# SuperMemory

Use `supermemory_search` when the current files do not fully establish a
project decision, durable constraint, prior incident, migration, or user
preference.

Treat returned memories as scoped, cited context:

1. Search with a narrow query.
2. Inspect the citation before relying on a consequential result.
3. Prefer current project files when they conflict with a memory.
4. Never claim access to conversation archives or another workspace.
5. If status reports local fallback, state that Hindsight ranking was
   unavailable; cited canonical memory remains authoritative.

Use `supermemory_status` for diagnostics. Use
`supermemory_explain_citation` to inspect provenance. A missing, stale,
restricted, revoked or out-of-scope memory must be treated as unavailable.
