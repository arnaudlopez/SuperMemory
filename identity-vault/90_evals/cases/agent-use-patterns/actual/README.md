# Agent Use Patterns Fixture

This fixture proves Tranche 10 without implementing runtime agents.

It checks that enterprise requests map to reusable use patterns:

- `external_draft`
- `internal_draft`
- `decision_support`
- `strategic_analysis`
- `audit_and_proof`
- `external_system_update`

The contract rejects bespoke workflow names and missing evidence, filters, review gates, snapshot citations, audit chains, or action confirmations.
