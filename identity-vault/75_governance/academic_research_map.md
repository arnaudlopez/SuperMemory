# Academic Research Map

- Personal Information Management: organize, retrieve, and forget personal information.
- Human-in-the-loop / Active Learning: ask useful clarification questions.
- Information Retrieval: BM25, embeddings, hybrid retrieval, reranking, recall, precision.
- Knowledge Graphs: entity and relationship modeling.
- Entity Resolution: aliases and duplicate identities.
- Coreference Resolution: pronouns such as him, it, this project.
- Temporal Knowledge Representation: validity over time.
- Provenance and Trust: source-backed memory.
- Privacy-Preserving Retrieval: permission-aware search.
- Agent Safety / Prompt Injection: hostile source handling.
- Evaluation of RAG and Agentic Systems: golden questions and canaries.
